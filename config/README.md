# config guide

## Prospective records research

`records_research.yaml` declares role-specific questions, candidate record
categories, alternative explanations and human routing review. It is a plan,
not a request archive or a source for claims of record existence.

## Research integrity

`research_integrity.yaml` names project-relative ledgers, digest manifests and
passage copies for the shared read-only checker. The default gate checks local
source declarations without requiring ignored original correspondence. It does
not change public-source review dates or domain clock/reference fields.
