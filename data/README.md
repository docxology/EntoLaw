# Data inputs and generated register

- [Claim ledger](claim_ledger.yaml) binds external statistics and volatile
  claims to bibliography keys, manuscript anchors and dated source quotes.
- [CourtListener cache](courtlistener_cache/) contains normalized, first-page
  search responses keyed by query ID.
- [Case candidates](case_candidates.yaml) is the generated register of search
  leads. Follow the [cache and register workflow](../docs/CASE_CANDIDATES.md)
  for refresh, offline verification and review of candidate opinions.
